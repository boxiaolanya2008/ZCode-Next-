# HTML / CSS 编写规范

> 适用于 HTML 与 CSS(Web 页面、组件、样式)。用户需求模糊时,先按本规范明确目标浏览器与设计语言,再实现。

## 1. HTML 语义与结构

- 用语义化标签(`section/article/nav/header/footer`),有明确无障碍语义;按钮/链接语义正确。
- 文档内标题层级清晰,`alt` 属性、`lang`、可访问性标注齐全。
- 不引入仅用于视觉效果的空 `div` 堆叠;结构与表现分离。

## 2. CSS 组织

- 用类选择器而非深层级标签/`id` 强耦合;优先级克制,避免 `!important` 泛滥。
- 复用设计 token(色彩、间距、圆角、字体)统一;不要把主题值散落在样式里。
- 组件样式收拢在同一文件/作用域,命名(BEM 之类)一致;保持可替换、可维护。

## 3. 布局与响应式

- 优先 flexbox/grid 表达布局,避免负 margin hack 与绝对定位堆叠。
- 以移动优先/响应式断点覆盖跨多宽;同时考虑深色模式与浏览器差异。
- 触控与指针、键盘焦点有可见态。

## 4. 性能与原生能力

- 图片/视频使用正确的加载与尺寸;避免阻塞渲染的大体积第三方脚本。
- 尽可能用原生 CSS/HTML 实现简单图形与状态,而非生成图占位。
- 动画克制并尊重 `prefers-reduced-motion`。

## 5. 安全

- 输出侧文本用转义,不把非可信输入直接拼进 `innerHTML`/`href`;校验 URL scheme。
- 避免内联不可信脚本;资源协议保持一致。

## 6. 常见陷阱

- 宽度/盒模型(`box-sizing:border-box`)、外边距塌陷;flex 换行与主轴对齐。
- 键盘焦点被 `outline:none` 隐藏;对比度不足。
